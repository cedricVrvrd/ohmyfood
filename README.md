# OhmyFood

🇫🇷 **Français** · [🇬🇧 English below](#english)

Projet de formation : site pour une plateforme de réservation de menus de restaurants gastronomiques, intégré à partir de maquettes fournies.

## Contenu

- `index.html` : page d'accueil
- 4 pages de menu : `aLaFrancaise.html`, `laNoteEnchantee.html`, `laPaletteDuGout.html`, `leDeliceDesSens.html`
- `design/sass/` : feuilles de style **Sass** (composants, pages, responsive)
- `maquettes/` : maquettes et animation de référence ; `Oh my food - Textes.txt` : textes du site

## Compétences travaillées

HTML · Sass · mise en page responsive · animations CSS

## Voir le site en local

Aucune dépendance : ouvrir `index.html` dans un navigateur. Pour modifier les styles, compiler les fichiers `.scss` de `design/sass/` avec Sass (`sass --watch design/sass`).

## 🇬🇧 English

Training project: a site for a gourmet restaurant menu booking platform, built from provided mockups.

**Contents:** home page, four menu pages, Sass stylesheets (`design/sass/`), reference mockups and animation (`maquettes/`).

**Skills practiced:** HTML, Sass, responsive layout, CSS animations.

**View locally:** no dependencies — open `index.html` in a browser. To edit styles, compile the `.scss` files with Sass (`sass --watch design/sass`).
